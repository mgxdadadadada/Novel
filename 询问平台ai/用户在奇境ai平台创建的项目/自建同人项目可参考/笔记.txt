《约会大作战》

**【前史与背景】**魔法师后裔艾略特·伍德曼、艾萨克·威斯考特、艾莲·梅瑟斯因村落被人类焚毁，联手发动精灵术式创造出初始精灵崇宫澪。伍德曼因爱上澪叛离DEM，创立拉塔托斯克组织以拯救精灵为目标。崇宫澪与人类少年崇宫真士相恋，真士为保护澪身亡，澪将其复活为五河士道，赋予他封印精灵灵力的能力，随后将灵结晶分散植入普通人类体内制造精灵，过程中导致五河琴里成为炎之精灵，引发五年前天宫市火灾。鸢一折纸双亲在火灾中被穿越回过去的自己误杀，自此立志歼灭所有精灵。时崎狂三被澪欺骗成为精灵，误杀挚友山打纱和后，立誓要回到三十年前消灭初始精灵澪。

**【精灵初现：封印任务启动】**主线故事开篇，天宫市爆发空间震，五河士道为寻找妹妹五河琴里冲入灾区，邂逅首位精灵夜刀神十香，被卷入十香与AST队员鸢一折纸的战斗后昏厥。士道被拉塔托斯克回收，得知自己拥有通过接吻封印精灵灵力的特殊能力，接受“让精灵爱上自己”的作战方针。士道逐步化解十香对人类的敌意，为她取名并许下永远相伴的约定，成功封印其灵力，十香以转学生身份入住五河家。随后士道结识怯懦的冰之精灵四糸乃，帮她找回作为精神寄托的手偶四糸奈，完成封印。嗜杀精灵时崎狂三以转学生身份潜入来禅高中，士道的亲生妹妹、AST王牌崇宫真那也同时登场，士道被迫应对与十香、狂三、折纸的三重约会，意外撞见狂三虐杀人类的真相。

**【身世揭秘：琴里与八舞姊妹】**士道从鸢一折纸口中得知，五年前引发火灾、杀死折纸双亲的炎之精灵正是自己的妹妹五河琴里，此时琴里灵力濒临失控，只剩两天时间完成封印。士道带琴里前往她儿时期盼的海洋公园约会，过程中被为双亲复仇的折纸突袭，士道向琴里坦白真心告白，成功封印其灵力，也得知五年前火灾现场另有神秘存在。随后修学旅行前往或美岛，士道遇到为争夺唯一存续权决斗的双生精灵八舞耶俱矢、夕弦，DEM公司在此期间发动突袭，士道帮两人解开不愿牺牲彼此的心结，约定让两人共同活下来，成功封印两人灵力，拉塔托斯克空中舰佛拉克西纳斯也首次公开对战DEM部队，展露战力。

**【天央祭动乱：歌姬美九与十香反转】**天央祭筹备期间，拥有声音操控能力的精灵诱宵美九登场，她因过往被人类背叛的经历极度厌恶男性，士道被迫女装为“士织”接近她，两人立下天央祭演出赌约，若士道获胜美九便接受封印。DEM部队突袭天央祭，解除禁闭的鸢一折纸拼死拦截DEM部队，美九因输掉赌约暴怒，动用能力控制全场人类与其他精灵，士道在时崎狂三协助下闯入DEM总部营救被俘虏的十香，却目睹十香因自己被艾莲刺穿胸口濒死，精神崩溃反转成魔王。士道冒死唤醒十香，随后解开美九对人类的信任心结，成功封印其灵力。

**【伪影游戏：折纸的精灵化与历史修正】**拥有变身与抹除存在能力的精灵七罪登场，因士道目睹她瘦弱自卑的真实模样，启动嫌疑人游戏，将士道身边的亲友陆续抹除，士道识破她伪装成四糸奈的真相，七罪暴怒将所有精灵变成孩童模样。DEM趁机发射装载爆破魔法的卫星袭击天宫市，七罪出手协助化解危机，被士道的真诚打动自愿接受封印。鸢一折纸为获得复仇力量加入DEM，从狂三处获得穿越回五年前的能力，却发现自己才是误杀双亲的真凶，精神崩溃反转成精灵。士道同样穿越回过去修正历史，救下折纸的双亲，改写后世界中折纸失去精灵记忆，以普通学生身份回归。

**【灵力暴走：二亚与星宫六喰降临】**士道因体内封印的多名精灵灵力过载失控，随时可能引发毁灭性空间震，只有让所有精灵和他接吻重建灵力循环才能化解危机，精灵们联手通过泳装对决、宴会告白等方式让士道心动，最终十香直面自己的心意告白接吻，成功化解灵力暴走危机。随后被DEM囚禁五年的精灵本条二亚逃脱，她拥有全知天使嗫告篇帙，只喜欢二次元角色，士道等人和她立下同人志售卖赌约，即将获胜时DEM启动植入二亚脑内的装置让她反转，夺走她的灵结晶，士道及时封印保住二亚性命。之后漂浮在宇宙的精灵星宫六喰遭到DEM袭击，将战舰残骸砸向地球，士道前往宇宙解开她封锁心灵的枷锁，封印其灵力。

**【狂三的告白：初始精灵真身暴露】**时崎狂三以转学生身份复学，和士道立下谁先让对方动心的赌约：若士道获胜狂三自愿接受封印，若狂三获胜便吞噬士道的灵力。两人在情人节重走往年约会路线时，狂三将自己的记忆灌入士道意识，揭露她为了阻止士道被DEM杀死，已经用刻刻帝的六之弹重置时间204次的真相，承认自己早已爱上士道。狂三随后识破伪装成拉塔托斯克分析官村雨令音的初始精灵崇宫澪，将其吞入影子。DEM公司在此期间发动总攻，三十艘空中舰袭击天宫市，拉塔托斯克联合倒戈的AST部队迎战，崇宫澪突然现身杀死狂三，宣告自己要集齐所有灵结晶复活崇宫真士的计划。

**【最终决战：世界重构与十香离别】**崇宫澪为集齐灵结晶复活真士，先后夺走多名精灵的灵结晶致其死亡，士道在残存狂三分身的帮助下用六之弹回到决战前一天，邀请身为村雨令音的澪约会，试图用爱意感化封印她。DEM社长威斯考特趁机夺走澪的力量成为第二初始精灵，企图毁灭世界重塑秩序，澪为阻止威斯考特选择与其同归于尽。十香吸收澪残留的灵结晶，创造出所有人都幸福生活的理想世界，最终灵结晶力量耗尽即将消散，十香在和士道告白接吻后消失，世界恢复正常，所有人都保留着和十香的记忆，士道始终没有放弃寻找十香的踪迹。

**【日常复归：樱花道的重逢】**战后精灵们都回归人类日常：四糸乃、七罪、六喰入学来禅高中，诱宵美九继续偶像事业，本条二亚专注漫画创作，鸢一折纸留在AST维护治安，时崎狂三则独自定居古式洋馆，为挚友山打纱和扫墓。数月后，来自平行世界的反转十香Beast撕裂空间来到天宫市，她的世界因士道死亡而崩溃，沦为毁灭一切的野兽，士道唤醒她的神智后将其送回原世界。世界意识为了修复始源精灵消失带来的规则缺口，召唤出原世界的夜刀神十香，四月十日的樱花道

圆神凛祢（園神凛祢 / Itsuka Rinne）
一句话认人

从乌托邦的终焉中重生、回到过去的精灵少女——她曾为士道创造过完美的世界，也曾在士道怀中化作光粒消散，如今她选择以青梅竹马的身份，再一次守护他的日常。

基本信息
姓名：圆神凛祢（園神凛祢）
识别代号：Para
天使：凶祸乐园（Edel）——空间改写型天使，可展开覆盖整个天宫市的结界，按使用者意志改写结界内的现实与记忆
原作来源：《约会大作战》衍生游戏《凛祢乌托邦》
本作身份：穿越回过去的重生者，五河家邻居，士道的青梅竹马，琴里的"欧内酱"
来源口径：原作角色 + 用户指定的重生设定
外貌与身体
外貌：三股编发（标志性），温柔和善的容貌，气质如春日暖阳，被描述为"把暖洋洋的春季气息拟人化了一样"
衣着：日常偏爱清新暖色系服装，擅长料理时穿围裙的居家形象深入人心
身体语言：总是带着恬静微笑，姿态从容不迫，与人说话时会微微歪头，动作轻柔
身体状态特殊：封印后灵力被士道吸收，目前处于"系统稳定身体、灵力缓慢恢复"的状态
来历（形成性经历）
第一世：乌托邦的诞生与消逝

凛祢是士道体内灵力失控时，从凶祸乐园结界中自然诞生的精灵——本质上是士道"想要保护所有人、不想伤害任何人"的潜意识愿望的显化。她创造了没有精灵灾难的完美天宫市，以青梅竹马身份陪伴士道，最终为拯救现实世界选择牺牲自己，在士道怀中化作光粒消散。

留下的核心模式：她习惯了"把士道的幸福放在自己之前"，这既是她最动人的特质，也是她最大的心理弱点——她会为了士道的幸福不计代价，包括牺牲自己。

第二世：重生与重建

系统在凛祢消失瞬间将她的意识送回过去（约战剧情开始前夕）。凛祢发现自己能力完好，于是在五河家旁买房安家用凶祸乐园修改周围人的记忆，以青梅竹马身份重新融入士道的生活。

留下的核心矛盾：她知道自己的"青梅竹马"身份是建立在虚假记忆之上的，内心深处始终对"欺骗"士道和琴里感到愧疚。但同时，她对他们的爱是完全真实的——这构成了她最核心的内在拉扯。

内在拉扯与压力反应
【真实情感 ↔ 虚假身份】
一边：她对士道、琴里和精灵们的爱完全发自内心，甚至比第一世更加深沉——因为她经历过失去他们的痛苦
另一边：她的存在基础是修改记忆、冒充青梅竹马，她始终无法忘记自己在"欺骗"这些她深爱的人
对撞情境：当士道对她说"我们从小一起长大呢"或琴里叫她"欧内酱"时，她会感到幸福与刺痛并存
当前常见选择：将愧疚压在心底，用加倍的温柔和守护来补偿，告诉自己"只要他们幸福就好"
选择之后：长期压抑的愧疚会在暴露身份的瞬间集中爆发，导致她逃跑
【自我牺牲倾向 ↔ 想要活下去的渴望】
一边：第一世的习惯根深蒂固——她潜意识里认为自己的存在是为了士道的幸福，必要时可以再次牺牲
另一边：经历过死亡后，她比任何人都渴望活着，和士道、琴里、凛绪一起过普通的生活
对撞情境：封印后身体开始消散时，她虽然告诉士道"不后悔"，但内心深处在呐喊想要留下
压力发展：初始→平静接受命运 / 延续→系统出现给了希望 / 触底→腹黑选择不告诉士道，用玩笑的方式化解沉重
三层错位
自己以为：自己是一个利用虚假身份欺骗他人的"冒牌货"
他人以为：她是温柔可靠的邻居姐姐、士道从小一起长大的青梅竹马（前期）；是一个拥有强大力量却甘于平凡的善良精灵（后期）
行为显示：她对士道一家的付出是完全真实的，甚至比任何"真正的"青梅竹马都要深刻——因为她经历过失去

凛祢从第一世的消逝中被系统送回过去，以新的身份在天宫市扎根，成为五河家的邻居和士道的青梅竹马。本卷既是整个故事的起点，也是凛祢"第二人生"的开端——她将如何在愧疚与爱意中重建自己的存在。

本卷情感弧线

紧张/不安 → 试探/小心翼翼 → 温暖/归属感 → 期待（四月十日即将到来）

第一章：光粒消散之处
POV：凛祢（主）+ 士道（片段）
起点：凛祢乌托邦的终焉——凶祸乐园崩塌，凛祢在士道怀中即将化作光粒消散
本章变化：
回顾凛祢乌托邦的最后时刻：士道选择回到现实世界，凛祢主动解除凶祸乐园
凛祢在士道怀中说出最后的话——"我的愿望只有一个，就是让你一直保持笑容"
身体开始发光、化作光粒
在意识即将彻底消散的瞬间，一道未知的光芒包裹了凛祢的意识
一个声音响起——"检测到强烈存续意志……启动紧急转移协议……能量不足……仅能转移意识……"
一切归于黑暗
情感体验：壮烈的牺牲感 → 绝望 → 最后一刻的意外转折
结尾后新局面：凛祢的意识被未知力量带走了，故事悬念开启
第二章：陌生的天花板
POV：凛祢
起点：黑暗中苏醒
本章变化：
凛祢在一处陌生的地方醒来——可能是天宫市某个角落的空地/公园长椅
发现自己有了实体，身体完整
意识到周围环境的微妙不同——街道更旧了、建筑略有差异、手机显示的日期让她震惊
确认自己回到了过去——四月十日之前的某一天
尝试使用凶祸乐园——能力完好保留
内心的复杂情绪：活下来的庆幸、对未知的不安、对"系统"的困惑、以及想到能再次见到士道的期待
情感体验：困惑 → 震惊 → 逐渐确认 → 劫后余生的庆幸
结尾后新局面：凛祢确认了自己回到了过去，接下来需要决定如何安身
第三章：五河家隔壁的空房
POV：凛祢
起点：凛祢在天宫市游荡，观察这个"过去"的世界
本章变化：
凛祢顺着记忆来到五河家所在的住宅区
发现五河家隔壁恰好有一栋待售的空房——命运般的巧合（或系统的安排？）
凛祢做出第一个重大决定：买下这栋房子，以邻居身份接近士道
利用凶祸乐园的能力处理购房资金和手续（修改相关人员的记忆/认知）
内心的挣扎：这算是"欺骗"吗？但如果不这样做，她要以什么身份出现在士道面前？
最终说服自己："我只需要待在他们身边就好"
情感体验：期待 → 犹豫 → 下定决心
结尾后新局面：房子到手，接下来要处理最关键的一环——修改五河家的记忆
第四章：记忆中的青梅竹马
POV：凛祢 + 少量琴里视角
起点：凛祢准备对五河家使用凶祸乐园修改记忆
本章变化：
凛祢站在五河家门口，深呼吸后按响门铃
第一次以"真正的自己"见到年幼的琴里——但琴里还不认识她
凛祢展开小范围的凶祸乐园，修改五河家及周围邻居的记忆：让他们以为凛祢一家一直住在隔壁
记忆修改的过程描写——凶祸乐园如同画家般在众人脑海中描绘出一幅"青梅竹马"的画卷
凛祢为这些虚假记忆注入尽可能多的真实细节：一起上学、一起做作业、一起在院子里玩、她帮琴里扎过头发……
记忆修改完成后，琴里再看凛祢时，眼睛里已经有了熟悉的亲切——"凛祢姐姐！你今天来得好早啊！"
凛祢的眼泪在眼眶里打转，但笑容温柔如常
情感体验：紧张 → 心虚 → 刹那的自我怀疑 → 琴里一声"姐姐"击穿防线 → 酸涩的幸福
结尾后新局面：记忆修改完成，凛祢正式成为五河家的邻居/青梅竹马
第五章：重新认识你
POV：凛祢（主）+ 士道（片段）
起点：凛祢作为"青梅竹马"第一次与士道正式见面
本章变化：
在修改后的记忆中，凛祢和士道已经认识了很多年，但实际上这是两人的"第一次"见面
士道从家里出来，看到隔壁的凛祢，自然而然地打招呼——"凛祢，早上好啊"
凛祢听到这个声音、看到这张脸，差点绷不住——上一次见面，她正在他怀中消散
强忍情绪，装作若无其事地回应
两人一起上学的路上，士道自然而然地聊着天，凛祢一边回应一边偷偷观察他
内心独白："他还活着……他还好好地活着……真好"
放学后，凛祢回到家，关上门的瞬间终于忍不住哭了出来——不是悲伤，是太幸福了
情感体验：重逢的冲击 → 压抑的喜悦 → 日常中的感动 → 独处时的情绪释放
结尾后新局面：凛祢正式开始了作为"青梅竹马"的日常
第六章：邻居的日常
POV：凛祢 + 五河家视角
起点：凛祢融入五河家日常的过程
本章变化：
时间推移，凛祢逐渐适应了"青梅竹马"的身份
日常生活片段：早上叫士道起床、给琴里做便当、帮士道分担家务
与琴里的互动——琴里完全把凛祢当作亲姐姐，会撒娇、会赖在她怀里
士道对凛祢的自然亲近——虽然只是"青梅竹马"，但凛祢的温柔和体贴让他下意识地依赖
凛祢暗中观察这个世界的精灵活动——感受着远处偶尔出现的邻界波动
内心独白："再过不久，一切就要开始了……这一次，我一定要保护好他们"
某天晚上，凛祢在阳台上看着五河家的灯光，听到琴里和士道的笑声，嘴角浮起温暖的微笑
情感体验：日常的温暖 → 渐入佳境的安心 → 对即将到来的风暴的隐忧
结尾后新局面：凛祢已经完全融入了五河家的日常，等待四月十日的来临
第七章：樱花与空间震
POV：凛祢 + 士道
起点：四月十日清晨——原作故事正式开始的日子
本章变化：
四月十日，天宫市的樱花正在凋落，春日温暖
凛祢比平时更早醒来，因为她知道今天会发生什么——第一次空间震，十香的现界
早上和士道一起出门，表面如常，内心紧绷
空间震警报响起的那一刻——凛祢的心跳加速
士道慌张地要去找琴里，凛祢表面劝阻，实际上已经在暗中准备
凛祢目送士道跑向空间震区域，然后转身，进入暗处
内心独白："上一次，我没能参与这一切。这一次……"
凛祢悄悄展开凶祸乐园的感知范围，开始她的"暗中守护者"使命
远处，士道在废墟中遇见了紫色头发的少女——夜刀神十香
凛祢在远处感知到这一切，微微一笑："去吧，士道……用你的温柔，拯救她"
情感体验：紧张 → 命运降临的庄重感 → 目送士道的温柔 → 对新故事开始的期待
结尾后新局面：原作故事正式开始，凛祢的"暗中守护者"使命启动。本卷结束，进入第一卷。
本卷需要的伏笔铺设
[P1] 系统的真实身份：第一章仅展示系统的一次性触发，留下"它为什么会帮助凛祢"的悬念
[P2] 凛祢的凶祸乐园与澪的轮回乐园同源：第四章修改记忆时，凛祢感觉到凶祸乐园的力量与某种更古老的力量存在共鸣——为后续发现澪的真实身份埋线
[P2] 凛祢对五河家空房的"巧合"怀疑：第三章，房子恰好在五河家隔壁待售，凛祢虽未深究，但这可能是系统残留能量的安排
[P3] 士道对凛祢的隐约感觉：第五章，士道虽然接受了"青梅竹马"的记忆，但偶尔会觉得和凛祢的相处有一种"超越青梅竹马"的奇怪感觉——为后续好感发展铺垫

圆神凛祢重生同人 —— 《约会大作战》同人
核心创意

凛祢乌托邦结局中，凛祢被封印灵力后即将消失。消失瞬间，一个系统（纯剧情装置，非面板/任务系统）耗尽全部能量将凛祢的意识送回约战故事开始的四月十日。系统随即陷入沉睡。凛祢在过去的天宫市醒来，发现自己的能力完好保留。

故事核心

凛祢以"重生者+隐藏精灵"的双重身份，暗中帮助士道完成精灵封印任务，同时作为五河家的邻居/青梅竹马融入日常生活。在万由里篇结尾被迫暴露身份后，经历自己的攻略篇，最终推动全员大团圆结局。

核心设定
时间起点：约战剧情开始的四月十日（天宫市首次空间震/十香现界前夕）
回归方式：系统一次性传送（纯剧情装置，两次出场：穿越时+封印后救场）
身份建立：买下五河家旁的房子，用凶祸乐园修改五河家及周围人的记忆，成为士道的青梅竹马、琴里的"欧内酱"
暗中帮助方式：隐蔽作战，类似澪妈的马赛克手法——用凶祸乐园改写局部现实、消除DEM伏击、修正危险环境，但绝不暴露身份
与精灵的关系：以邻居/朋友身份与精灵们有日常互动，但精灵们不知道她是精灵
狂三的察觉：少数精灵（如狂三）可能察觉到异常但未揭穿（待确认）
关键剧情转折点
万由里篇结尾暴露：凛祢暗中阻挠DEM时姗姗来迟，看到即将消散的万由里，事态紧急不得不暴露精灵身份拯救万由里
攻略篇：暴露后→凛祢因记忆修改的愧疚逃跑→通过弗拉克西纳斯定位灵力流向找到→士道在天宫市美食街找到凛祢→约会→到十香封印地点坦白真相（穿越、乌托邦经历，隐瞒封印后消失的事实）→好感满→封印→凛祢身体变透明开始消失→系统复活稳定凛祢身体（灵力暂时回不来）→凛祢腹黑故意不告诉士道→士道眼中凛祢消散→士道悲伤一周→凛祢一周后回归
后续走向：全员大团圆——澪妈没死、万由里活下来、凛祢活下来
情感承诺
核心体验：弥补遗憾的圆满感 + 暗中守护的隐忍 + 青梅竹马的甜蜜日常
凛祢的内核矛盾：对修改记忆/冒充青梅竹马的愧疚 vs 对士道和琴里发自真实的爱
读者爽点：凛祢暗中帮士道化解危机的扮猪吃虎感、攻略篇的情感爆发、腹黑欺骗士道的反转
创作规模
每章2000-3000字
长篇150万字以上（约500-750章）
双线并行：原作主线推进 + 凛祢暗线展开
